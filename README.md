# Pandas I/O — Diferentes formatos de arquivos

Repositório criado durante meus estudos do curso
"Pandas I/O: trabalhando com diferentes formatos de arquivos",
da Alura.

O objetivo é praticar a leitura, manipulação e exportação de
dados utilizando Python e Pandas.

## Conteúdos

- CSV
- Excel
- JSON
- HTML
- XML
- SQL
- SQLite
- SQLAlchemy

## Tecnologias

- Python
- Pandas
- SQLAlchemy
- SQLite
- Jupyter Notebook

## Estrutura

- `notebooks/` — exercícios e práticas do curso
- `data/raw/` — dados originais
- `data/processed/` — dados processados
- `src/` — códigos auxiliares
